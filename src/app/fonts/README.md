# Local fonts

**Museo Sans** files (license required) referenced by `src/app/layout.tsx` via
`next/font/local`. Museo Sans has no 400 weight: its natural "regular" is the
**500** (Medium), used for body text.

| File                | Weight | Style  |
| ------------------- | ------ | ------ |
| `MuseoSans-100.otf` | 100    | normal |
| `MuseoSans-300.otf` | 300    | normal |
| `MuseoSans_500.otf` | 500    | normal |
| `MuseoSans_700.otf` | 700    | normal |
