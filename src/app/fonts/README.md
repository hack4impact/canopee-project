# Polices locales

Fichiers **Museo Sans** (licence requise) référencés par `src/app/layout.tsx` via
`next/font/local`. Museo Sans n'existe pas en graisse 400 : son « régulier »
naturel est le **500** (Medium), utilisé pour le texte courant.

| Fichier             | Poids | Style  |
| ------------------- | ----- | ------ |
| `MuseoSans-100.otf` | 100   | normal |
| `MuseoSans-300.otf` | 300   | normal |
| `MuseoSans_500.otf` | 500   | normal |
| `MuseoSans_700.otf` | 700   | normal |

> ⚠️ Les chemins exacts (y compris les tirets vs tirets-bas) doivent correspondre
> à la configuration. Si vous ajoutez des variantes italiques ou d'autres
> fichiers, indiquez-les pour ajuster `layout.tsx`.
